# Studiosuccess Bot — быстрый старт

## Рабочая папка проекта

```
~/claude/telegram-gpt-bot/
```

Все файлы, правки и запуск — только из этой папки.

Локально используется `venv/` (Python 3.9.6). На продакшн-сервере — отдельное окружение `.venv/`
(Python 3.12.3, см. `deployment/deploy.sh`) — это два разных venv, не путать пути.

---

## Режим разработки

Используется для:

* изменения кода;
* добавления сотрудников;
* изменения настроек;
* исправления ошибок.

### 1. Открыть Terminal

### 2. Перейти в папку проекта

```bash
cd ~/claude/telegram-gpt-bot
```

### 3. Активировать виртуальное окружение

```bash
source venv/bin/activate
```

После этого в начале строки должно появиться:

```
(venv)
```

### 4. Проверить содержимое папки

```bash
ls -la
```

Должны присутствовать:

```
.env
bot.py
venv
```

### 5. Открыть файлы

Открыть код:

```bash
open bot.py
```

Открыть настройки:

```bash
open .env
```

### 6. После любых изменений

Сохранить файл, затем проверить код:

```bash
python3 -m py_compile bot.py
python3 -m py_compile services/*.py
python3 -m py_compile scripts/*.py
```

Если ошибок нет, Terminal просто покажет новую строку.

Если в проекте есть тесты (`tests/`), также запустить:

```bash
python3 -m pytest tests/
```

## Режим тестирования

Используется для проверки бота в Telegram.

### Запустить бота

Находясь в папке проекта и с активным venv:

```bash
python3 bot.py
```

Если ошибок нет, Terminal будет ждать новые сообщения Telegram.

### Остановить бота

В любой момент:

```
Ctrl + C
```

После этого бот перестанет отвечать и Terminal снова станет доступен.

## Добавление нового сотрудника

**Шаг 1**

Получить Telegram ID сотрудника через:

```
@userinfobot
```

**Шаг 2**

Открыть:

```bash
open .env
```

Добавить ID в `STAFF_USERS` (через запятую). Пример:

```env
STAFF_USERS=111111111,222222222,333333333
```

**Шаг 3**

Сохранить файл, проверить код и перезапустить бота:

```bash
python3 -m py_compile bot.py
python3 bot.py
```

Больше ничего править не нужно — команды и кнопки сотрудника определяются только через
`STAFF_USERS`, отдельного реестра личных доступов в текущей версии бота нет.

## Проверка работы сотрудника

В Telegram написать:

```
/start
```

Должна появиться кнопка «Выбрать проект» (и «📚 Инструкции»).

## Проверка работы заказчика

В Telegram написать:

```
/start
```

Должна появиться кнопка «Заполнить бриф». Внутренних кнопок сотрудника видно быть не должно.

---

## Основные команды сотрудника (текстовые)

`/chat_id` — показать chat_id/thread_id текущего чата (для регистрации рабочих групп).

`/register_chat <slug>` — зарегистрировать текущую группу/топик под именем `<slug>`.

`/chats` — список зарегистрированных рабочих чатов.

`/send_test_to_chat <slug>` — отправить тестовое сообщение в зарегистрированный чат.

`/project_chat_status` — показать, какие групповые чаты привязаны к каким клиентским проектам.

Выбор клиентского проекта, просмотр брифа и режим вопросов по проекту делаются только через
кнопки `/start`, отдельных текстовых команд для них нет.

## Добавление / изменение клиентского проекта

Проект появляется в `config/projects.json` автоматически после того, как клиент заполнит бриф
через кнопку «Заполнить бриф». Ручное добавление/скрытие проекта — см. `PROJECTS_REGISTRY.md`.

## Если что-то сломалось

Проверить код:

```bash
python3 -m py_compile bot.py
```

Если появилась ошибка:

```
IndentationError
SyntaxError
NameError
```

Исправить ошибку и повторить проверку.

Логи бота — в `logs/bot.log` (локально) или `journalctl -u studiosuccess-bot.service` (на сервере).

## Резервная копия

Создать копию bot.py:

```bash
cp bot.py backups/bot_backup_before_changes.py
```

Восстановить:

```bash
cp backups/bot_backup_before_changes.py bot.py
```

Перед крупными изменениями всегда делать новую резервную копию.
