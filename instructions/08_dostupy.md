## Общий аккаунт ChatGPT

### Правила работы

1. Для каждого проекта используется отдельная папка в разделе «Проекты».
2. Перед началом работы обязательно проверьте название проекта.
3. Работайте только внутри папки нужного проекта.
4. Не открывайте, не редактируйте и не удаляйте материалы других проектов.

### Авторизация

1. Откройте https://www.google.com/ и войдите в рабочий аккаунт `mossssina@gmail.com`.

4. Откройте https://chatgpt.com/ и выберите вход через Google.
