# ROADMAP.md — Telegram GPT-бот Studiosuccess

## ✅ Реализовано

- Три уровня доступа: заказчик / сотрудник / личная папка
- Проверка роли сотрудника по Telegram ID через STAFF_USERS (7 человек)
- Проверка доступа к личной папке по Telegram ID через PERSONAL_*
- Список из 25 клиентских проектов
- Выбор активного клиентского проекта через /project
- Выбор личной папки через /personal (с проверкой владельца)
- Блокировка рабочих команд без активного клиентского проекта
- Блокировка личных папок для чужих сотрудников
- Разделение контекста GPT: клиент / личная папка / заказчик
- Команда /current — показывает активный проект
- Команда /help — показывает команды по роли
- Резервное копирование bot.py перед правками
- Clean message logic — удаление предыдущего системного меню
- Inline-кнопки для сотрудника в /start
- Inline-кнопки для заказчика в /start
- Кнопка «Личная папка» — только если у сотрудника есть доступ
- handle_button — маршрутизация всех 14 callback-кнопок
- Редактирование сообщения при нажатии кнопки (query.edit_message_text)
- Все текстовые команды сохранены параллельно с кнопками
- Личный чат сотрудника — один на каждого, открывается автоматически при входе в личную папку
- Папки `personal_projects/` для 7 сотрудников созданы
- `personal_slug()` — нормализация имён (пробел/подчёркивание)
- Починен баг в `/personal`: команда теперь работает и с пробелом, и с подчёркиванием
- `require_client_project()` — умное сообщение для personal mode

## ⚠️ Частично реализовано

- **GPT-интеграция** — код написан, но модель `gpt-5.5` вероятно не существует;
  используется `client.responses.create` вместо `client.chat.completions.create`.
  Требует живой проверки при запуске.

- **Клиентские команды** — зарегистрированы и отвечают инструкцией,
  но не передают текст пользователя в GPT и не возвращают реальный разбор.

- **select_personal через текст** — ключи в PERSONAL_ACCESS используют подчёркивание
  (`"anastasiia_mosina"`), команда `/personal anastasiia mosina` (с пробелом) не сработает.
  Через кнопку работает корректно — callback передаёт готовый ключ.
